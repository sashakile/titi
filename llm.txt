# titi

> Small CLI tool for managing C# monorepos.

**TL;DR:** titi manages .NET monorepo reference modes (PackageReference ↔ ProjectReference), generates transient solutions, and computes test-impact analysis from git diff + coverage data.

## What it does

titi is a C# 13 / .NET 10 command-line tool that provides an orchestration
layer for .NET monorepos. It manages the tension between treating a module as
an independent NuGet package vs. a local project reference.

## Core capabilities

- **Reference swapping** — toggle between `PackageReference` (binary mode) and
  `ProjectReference` (source mode) using MSBuild conditional logic
- **Dependency graph analysis** — uses `Microsoft.Build.Graph` to build a DAG
  of the entire monorepo and identify affected projects
- **Dynamic solution generation** — creates transient `.slnx` files scoped to
  a target project and its transitive source-dependencies
- **Test Impact Analysis** — project-level and method-level test selection from
  git diff + Cobertura coverage edges, with multi-factor confidence scoring
- **testaruda adapter** — built-in JSON-over-stdio adapter protocol for
  testaruda integration

## Key design decisions

- Functional-core / imperative-shell: graph analysis and transformation are
  pure functions; filesystem I/O and MSBuild calls are in the shell layer
- Projects stay "clean" by default (PackageReference only); ProjectReference
  mode is only active when the tool generates a custom solution
- `AssemblyVersion` is pinned to `{Major}.0.0.0` to prevent runtime binding
  failures across patches
- Lock files (`packages.lock.json`) are required and enforced in CI via
  `RestoreLockedMode`

## Project structure

```
src/titi/
├── Adapter.cs           — testaruda adapter protocol
├── Affected.cs          — Impact analysis (git diff → affected projects)
├── Core.cs              — Entry point + command dispatch
├── Domain.cs            — Core domain model (records, enums)
├── Graph.cs             — MonorepoGraph construction
├── Config.cs            — titi.config.edn loading + defaults
├── Swap.cs              — Reference swapping (PackageRef ↔ ProjectRef)
├── Solution.cs          — .slnx solution generation
├── TestDiscovery.cs     — `dotnet test --list-tests` parsing
├── Coverage.cs          — TRX + Cobertura XML parsing
├── Safety.cs            — Selection safety (always-run, confidence)
├── Repl.cs              — Interactive dependency graph REPL
├── Serialization/       — AOT-safe JSON (TitiJsonContext + DTOs)
│   └── TitiJsonContext.cs
└── titi.csproj          — Project file
test/
└── titi/
    ├── AffectedTests.cs
    └── ...
```
